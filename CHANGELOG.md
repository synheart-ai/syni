## [0.1.0] - 2026-01-15

### Added

- Initial specification release for Syni (persona-driven interaction layer)
- Core concepts: Personas, Persona Engine, CCO (Context · Constraints · Output), PPE (Persona · Policy · Execution), HSI integration, Safety Model, On-Device vs Cloud modes
- SDK specifications: syni-flutter, syni-kotlin, syni-swift
- Runtime specification (syni-runtime)
- Behavioral contract (syni-spec)
- Guides: Building with Syni, Creating Personas, SDK Overview
- Glossary of key terms
- CONTRIBUTING.md
